# 啃读点书吗？ — Chrome 扩展

中文阅读重点标注 + 跟读节奏模式，帮 ADHD 人群专注阅读。斑点狗陪读，阅读时长换狗狗币解锁新品种。

**灵感来源**：本项目受到小红书用户 **@好的夏洛特** 与 **@无用的好奇** 关于阅读专注/重点标注分享的启发，特此致谢。

## 产品介绍

打开任意中文网页，「啃读点书吗？」会自动：

- **标重点**：用「静态规则 → 本地 BERT 语义 → 可选 AI 大师校准」三层打分，找出文章里真正重要的信息点，按重要程度以琥珀色渐变高亮（相邻重点自动合并成短语，人名不会霸屏）；
- **带你读**：切到「跟读模式」，一只小狗从文首匀速扫读，读过的字淡出、重点词被跳过幸存，可调速、可暂停/继续/重读、换页续读、自动滚屏；
- **陪你读**：活动阅读 1 分钟 = 1 🦴 狗狗币，攒币在狗舍解锁 15 种小狗（新装可免费任选一只初始狗狗）。

**隐私**：分词词典与打分模型全部随扩展本地运行，文本不出浏览器；AI 校准默认走免费接口、含密码框/内网页面自动跳过上传，可一键关闭。

## 安装使用

1. 下载本项目到本地（或解压发布包 `kddsm-v1.0.0.zip`），得到一个含 `manifest.json` 的目录；
2. 打开 Chrome（Edge / 360 极速等 Chromium 浏览器均可），地址栏输入 `chrome://extensions`；
3. 打开右上角「**开发者模式**」开关；
4. 点击「**加载已解压的扩展程序**」→ 选择第 1 步的目录；
5. 完成：工具栏出现斑点狗小狗图标。

**验证**：打开任意中文文章页 → 页面自动出现琥珀色高亮；点工具栏小狗图标 → popup 切「跟读」→ 小狗出现并逐字扫读。

> 本地 `file://` 网页需要在扩展详情里开启「允许访问文件网址」；`演示视频.mp4` 未入库时，演示请以 `assets/demo.gif` 为准。
